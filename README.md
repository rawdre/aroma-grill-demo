# Aroma Grill landing page

[Live website](https://rawdre.github.io/aroma-grill-demo/)

A responsive, dependency-free website concept for Aroma Grill Brazilian BBQ. Open `index.html` using a static server. GitHub Pages serves the repository root.

## Features

- Higgsfield hero video and cinematic imagery, with a still-image fallback
- Responsive mobile navigation and keyboard-accessible menu tabs
- Catering request preview with copy-to-Instagram handoff; no backend or claim of a sent inquiry
- Reduced motion support, video pause control, focus states, semantic sections, and social metadata

## Content notes

Menu names and visible prices come from supplied screenshots. Plate and sandwich prices were not visible and are intentionally omitted. Hours, address, booking availability, and service area are not invented. Instagram is the destination for current updates and inquiries. Confirm business details before a production launch.

Original logo and menu photography were cropped from user-supplied screenshots. The truck reference was extracted from the user's video. Cinematic truck and fire images and the hero video are AI-generated through Higgsfield, based on the supplied brief/reference. They are concept visuals, not documentation of a real location or event.

No dependencies, secret keys, tracking, or personal data storage. Form data remains in the browser until the visitor copies and sends it themselves.
